# Aviso legal y método de creación

**MiniEstudio** es una aplicación original creada con [ClonaKit](https://www.divisualproject.academy), inspirada en las funciones de **OBS Studio**.

No contiene código, textos, imágenes, iconos, sonidos, nombres ni marcas de OBS Studio. OBS Studio es un proyecto de código abierto con licencia GPL-2.0 y su nombre y logo pertenecen a sus titulares; este proyecto no está afiliado a ellos ni cuenta con su respaldo.

## Cómo se ha creado (método de sala limpia)

1. **Investigación** (12 de octubre de 2026): se observó el funcionamiento de OBS Studio 32.2.2 como usuario legítimo y se analizó su estructura con REA (permisos, frameworks del sistema y plugins) para entender sus funciones y tecnologías. No se leyó ni se usó su código fuente.
2. **Especificación** (12 de octubre de 2026): se escribió una ficha funcional con palabras propias ([FICHA.md](../FICHA.md)).
3. **Construcción** (12 de octubre de 2026): el código se escribió desde cero con APIs estándar del navegador, tomando como única referencia esa ficha.
